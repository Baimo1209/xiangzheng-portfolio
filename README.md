# 项征｜个人项目与技术文章

项征的实名个人网站，独立于原有 `Baimo1209.github.io` 博客。

网站围绕以下内容组织：

- 华中科技大学人工智能专业学习与本科科研经历
- YOLOv8、计算机视觉与多模态 AI 研究兴趣
- Android 本地应用、AI Agent 与 LightDiff 项目
- Windows 工程诊断、自动化和项目交付方法
- 项目复盘与技术文章归档

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

原博客不在本目录中，新站的内容和发布流程互不覆盖。
